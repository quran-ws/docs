## الأساس — `core`

### Mushaf — المصحف

| | |
| --- | --- |
| `code` | `mushaf` |
| `plural` | `mushafs` |
| `kind` | `entity` |
| بالحركات | المُصْحَف |
| تهجئات أخرى | `mus'haf`، `muṣḥaf` |
| مقابل إنجليزي | `Quran Codex` |

**التعريف:** الصحف التي جمع فيها القرآن مكتوبًا ومرتبًا؛ فالمصحف وعاء مكتوب للقرآن وليس مرادفًا مطلقًا للقرآن نفسه.

**الغرض:** يستخدم عندما تكون خصائص التمثيل المكتوب للقرآن مهمة، مثل الرسم والتخطيط والصفحات والأسطر والعلامات.

### Quran — القرآن

| | |
| --- | --- |
| `code` | `quran` |
| `kind` | `concept` |
| بالحركات | القُرْآن |
| تهجئات أخرى | `koran`، `qur'an`، `qur’an` |

**التعريف:** كلام الله المنزل على محمد ﷺ والمتعبد بتلاوته، ويطلق على مجموعه وعلى بعضه بحسب السياق.

**الغرض:** يمثل المحتوى القرآني نفسه بصورة مستقلة عن مصحف أو تخطيط أو تنسيق أو تمثيل رقمي معين.


## البنية — `structure`

### Ayah — آية

| | |
| --- | --- |
| `code` | `ayah` |
| `plural` | `ayahs` |
| `kind` | `entity` |
| بالحركات | آيَة |
| تهجئات أخرى | `aya` |
| مقابل إنجليزي | `verse` |

**التعريف:** وحدة من النص القرآني تقع ضمن سورة ولها حدود محددة، وقد يختلف رقمها أو بعض حدودها باختلاف نظام عد الآي.

**الغرض:** تستخدم كوحدة أساسية للإشارة إلى النص القرآني وربط الترجمات والتفاسير والتلاوات والتحليلات والبيانات الأخرى بموضع محدد من القرآن.

- موقعها في صفحة أو سطر يخص المصحف أو الـlayout، لا هوية الآية نفسها.
- الفاصلة نهاية الآية، وليست الآية.
